Design

为「元游戏」而生

这些能力通常需要自己写 C++、处理 Windows 消息循环、再手动绑回游戏。这里已经做完了。

单文件部署

把 qiumingdll.dll 放到与 data.win 同级的目录，调用一次 qiumingdll_init() 即完成全部函数绑定。

多引擎可用

GameMaker 直接走 GML 包装；仓库同时提供 Unity / Godot 的 C# 绑定，以及 Undertale Mod Tool 的导入脚本。

优雅降级

非 Windows 平台上，所有包装函数直接返回默认值，游戏照常运行；init 幂等，重复调用没有副作用。

Quickstart

三行起步

下面是把主窗口一分为二、右侧面板弹入的完整流程。所有函数文档都有签名、返回值表与示例。

  1. 01

    放置 DLL

    按游戏位数选择 x32 或 x64 的 qiumingdll.dll，与 data.win 放在同一目录。

  2. 02

    初始化

    在创建事件里调用 qiumingdll_init()；用到哪个模块，再调它的 _init()。

  3. 03

    调用与清理

    直接调 API；房间结束或游戏退出时调用对应的 _cleanup() / qiumingdll_free() 释放资源。

// 绑定全部外部函数（仅 Windows 生效，可重复调用）
qiumingdll_init();
qiumingdll_fixflash();   // 可选：消除窗口重绘闪烁

// 窗口分裂模块
if (qiumingdll_winsplit_init() == 0)
{
    var _cw = window_get_width();
    var _ch = window_get_height();

    // 源区域 → 屏幕坐标；返回 1~16 的 splitId
    var _panel = qiumingdll_winsplit_create(
        _cw div 2, 0, _cw div 2, _ch,
        80, 80, _cw div 2, _ch
    );

    qiumingdll_winsplit_set_easing_curve(_panel, 10); // bounce-out
    qiumingdll_winsplit_set_position_animate(_panel, 40, 40, 600, 16);
}

// 内联输入法：让候选框贴着输入光标
qiumingdll_ime_set_inline_position(input_x, input_y + 24);

// 麦克风音量（0 = 成功）
qiumingdll_volume_start(48000, 10);
